Ellipse Perimeter Interactive Demo

This demo compares the proposed R2/F3EXP model against the numerical reference obtained via the complete elliptic integral of the second kind.

Model

P ≈ P_R2 / (1 − [A·exp(-B(1-h)^q) + C·exp(-D(1-h)^r) + E·exp(-F(1-h)^s)])

where h = ((a − b)/(a + b))² and P_R2 is Ramanujan’s second approximation.
